# SQL Customer & Order Analysis

## Overview

This project uses SQL to analyze customer spending and order activity. A relational database was created containing customer and order information, then SQL queries were used to retrieve, aggregate, and analyze the data.

## Tools Used

- SQL
- SQLite

## Database Tables

### Customers
- Customer_ID
- Name
- City
- Total_Spent

### Orders
- Order_ID
- Customer_ID
- Product
- Quantity

## SQL Concepts Demonstrated

- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- SUM
- AVG
- COUNT
- GROUP BY
- JOIN
- ORDER BY
- Primary Keys
- Foreign Keys

## Analysis Performed

- Found customers located in Atlanta
- Calculated total spending in Atlanta
- Calculated average spending in Atlanta
- Calculated total spending by city
- Calculated average spending by city
- Counted customers by city
- Joined customer and order information
- Filtered orders from Atlanta customers
- Calculated total quantities ordered by customer
- Ranked customers by total quantity ordered
